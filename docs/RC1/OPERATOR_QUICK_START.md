# Quick-Start Operator Guide — RC1

## Before service (15 minutes)

1. Launch app · verify **v1.0.0-rc.1**
2. Help → **Pre-Service Checklist**
3. Open **Local projector** output
4. Optional: **Stage Display** + **OBS** test connection
5. Load today's service plan in **Service Builder**

## Entering live worship

1. **Service Mode** (touch-friendly) or **Presenter** dashboard
2. Enable **Quiet Service Mode** if desired (admin)
3. Set **Next** hymn while current hymn is Live
4. **Take Next** only when ready — congregation stays on current output if preparation fails

## Core controls

| Action | Control |
|--------|---------|
| Preview selection | Enter |
| Send Live | Ctrl/Cmd + Enter |
| Next stanza | Space / → |
| Take Next hymn | Shift + ] |
| Restore previous hymn | Shift + [ |
| Clear | C |
| Show Logo | L |
| Blackout | B |
| Emergency Help | Ctrl/Cmd + Shift + E |

## Bible during sermon

1. Type reference in Bible Live search
2. Preview loads — verify version
3. Send Live when preacher is ready
4. Advance verses with Alt + → / ←

## If something fails

- Congregation output unchanged? **Do not panic** — failed Live switches preserve current content
- Projector blank? **Restart Output** in Service Mode emergency strip
- App crashed? Relaunch — **Session Recovery** offers restore
- OBS disconnected? Local projector continues; fix OBS in Settings

## After service

1. Save service plan changes
2. Exit Service Mode cleanly
3. Close outputs
4. Quit app normally (enables clean session exit flag)
