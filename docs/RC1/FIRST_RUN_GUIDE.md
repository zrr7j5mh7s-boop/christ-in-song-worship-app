# First-Run Guide — VaChinoda Worship App RC1

## 1. Launch and verify version

- Open the app; confirm **VaChinoda Worship App · v1.0.0-rc.1** in Settings or Help → About.

## 2. Church branding

1. Go to **Settings**.
2. Enter church name.
3. Upload church logo (optional).
4. Save — logo appears on congregation **Show Logo** screen.

## 3. Outputs

1. **Settings → Outputs** — choose Local projector destination.
2. Open **Presenter** → **Open Output** on the correct display.
3. Optional: **Stage Display** on a secondary monitor for worship team.

## 4. Hymnal library

1. Open **Hymnal Library**.
2. Confirm **Christ in Song** and **SDA Hymnal** appear.
3. Select your default language/edition.

## 5. Bible

1. Open **Bible** reader — confirm KJV loads.
2. Open **Bible Live** — test a reference in Preview before Send Live.

## 6. Service Builder

1. Create a short test service (welcome, hymn, Bible reading).
2. Save the plan.

## 7. Backup

1. Settings → **Backup & Restore** → Create Full Backup.
2. Store the `.csbackup` file safely.

## 8. Pre-service checklist

Help Centre → **Pre-Service Checklist** — complete before first live Sabbath.

## 9. Operator training

- Practice **Service Mode** without congregation present.
- Learn keyboard shortcuts: `/` focus search, Enter Preview, Ctrl/Cmd+Enter Send Live.
- Test **Clear**, **Blackout**, and **Restore Previous** from emergency strip.
